## Name

reader

## Short description (one line)

Open-source Google Reader clone — read RSS/Atom in a desktop app or self-hosted web service, with OPML import, snooze, saved lists, and social-timeline ingestors.

## Long description

reader is an open-source (MIT) feed reader that recreates the classic
Google Reader workflow. It runs as an Electron desktop app or a self-hosted
web service from one TypeScript codebase, with a local SQLite database and
no account requirement.

- Classic three-pane UI (feeds, article list, article view) plus a mobile
  layout with swipe navigation and an installable PWA
- OPML import to move subscriptions from Feedly, Inoreader, FreshRSS, and others
- Snoozed articles stay unread and resurface on their own
- Saved lists, private or public — every public list is an RSS feed
- Ingestors pull Mastodon, Bluesky, or Reddit timelines in as feeds, or merge
  several feeds into one AI-filtered, summarized view
- Unread-only navigation: jump between unread articles with buttons, swipe,
  or the keyboard
- Pinboard view for image-led feeds
- Article bodies sanitized server-side against XSS

Try the demo: https://dev.standardbeagle.com/reader/demo/
Source: https://github.com/standardbeagle/reader
